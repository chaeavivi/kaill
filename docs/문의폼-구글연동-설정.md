# 문의 폼 → 구글 시트 연동 설정 가이드

웹사이트의 3개 문의 폼(B2B 출강 / 강사양성 / 일반·제휴)에서 접수된 내용을
**구글 시트에 자동으로 쌓이게** 하는 설정입니다. 서버 없이 동작하며, 무료입니다.

---

## 1단계 — 구글 시트 만들기
1. https://sheets.google.com 에서 **새 스프레드시트**를 만듭니다. (이름 예: `문의 접수`)
2. 이 시트에 문의가 자동으로 쌓입니다. (탭 이름 `문의`는 스크립트가 자동 생성)

## 2단계 — Apps Script 붙여넣기
1. 그 시트 상단 메뉴에서 **확장 프로그램(Extensions) → Apps Script** 클릭.
2. 기본 코드를 모두 지우고, 저장소의 [`docs/google-apps-script.gs`](./google-apps-script.gs) 내용을 **전부 복사해 붙여넣기**.
3. (선택) 알림 이메일을 받으려면 상단 `NOTIFY_EMAIL` 값에 이메일을 넣습니다.
   예: `var NOTIFY_EMAIL = 'contact@kaill.or.kr';`
4. 💾 저장.

## 3단계 — 웹앱으로 배포
1. 우측 상단 **배포(Deploy) → 새 배포(New deployment)**.
2. 유형(⚙️ 톱니) → **웹 앱(Web app)** 선택.
3. 설정:
   - **실행 계정(Execute as):** 나(본인)
   - **액세스 권한(Who has access):** **모든 사용자(Anyone)**  ← 반드시 이걸로!
4. **배포** 클릭 → 권한 승인(구글 계정 로그인·허용).
5. 나오는 **웹 앱 URL**을 복사합니다.
   형식: `https://script.google.com/macros/s/AKfy....../exec`

## 4단계 — 사이트에 URL 연결
`src/data/site.ts` 파일의 아래 줄에 복사한 URL을 붙여넣습니다.

```ts
export const INQUIRY_ENDPOINT = 'https://script.google.com/macros/s/AKfy....../exec';
```

저장 후 `main`에 반영(커밋·병합)하면, 다음 자동 배포부터 문의가 구글 시트에 쌓입니다.

> 💡 이 URL만 알려주시면 제가 대신 `site.ts`에 넣고 배포까지 처리해 드립니다.

---

## 동작 방식 / 참고
- URL이 **비어 있으면**: 사이트는 "접수 완료" 화면만 보여주는 **데모 상태**로 동작하고 실제 저장은 되지 않습니다.
- URL이 **설정되면**: 폼 제출 시 위 웹앱으로 전송되어 시트에 한 줄씩 기록됩니다.
- 전송은 브라우저에서 `no-cors`로 이뤄지므로, 사용자에게는 항상 성공 화면이 보입니다.
  (스팸/오류 여부는 시트에 실제로 쌓이는지로 확인하세요.)
- 스크립트를 **수정**한 뒤에는 반드시 **새 버전으로 다시 배포**해야 반영됩니다.
  (배포 → 배포 관리 → 편집 → 새 버전)
