# 출강 후기 연결하기 (처음 한 번만)

강의 현장에서 QR로 받은 후기가 홈페이지 **강사 출강 → 출강 후기**에 바로 올라가게 하는 설정입니다.
문의 폼과는 **별개**라서, 문의 폼에는 영향이 없습니다.

## 1. 후기 보관용 구글 시트 만들기
1. 구글 드라이브 → **새로 만들기 → Google 스프레드시트**
2. 파일 이름: `출강 후기 저장소` (아무 이름이나 괜찮습니다)

## 2. 코드 붙여넣기
1. 그 시트 상단 메뉴 **확장 프로그램 → Apps Script**
2. 처음 보이는 코드를 **전부 지우고**, 이 저장소의 `docs/review-apps-script.gs` 내용을 **전부 복사해서 붙여넣기**
3. 💾 저장 (Ctrl+S)

## 3. 배포하기
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 구글 계정 선택 → "확인되지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**
   (내 계정에서 내가 만든 스크립트라 안전합니다)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사

## 4. 주소 전달
복사한 URL을 Claude에게 보내주세요. 홈페이지에 넣고 올립니다.
(직접 넣을 때: `src/data/site.ts`의 `REVIEW_ENDPOINT = ''` 따옴표 안에 붙여넣기)

## 운영 방법
- 강의 마지막에 `docs/qr/후기QR-강의슬라이드.png`를 화면에 띄우거나, `후기QR.png`를 교안에 넣으세요.
- 후기는 **바로 공개**됩니다. 욕설·광고·링크·전화번호·장난 글은 **자동 차단**되어 홈페이지에 안 나옵니다.
- 시트에는 차단된 글도 사유와 함께 기록됩니다 (D열 '자동검사').
- 혹시 이상한 글이 올라갔다면: 시트에서 그 줄의 **F열(상태)을 `숨김`으로** 바꾸면 즉시 내려갑니다.
  반대로 잘못 차단된 글은 `공개`로 바꾸면 올라갑니다.
- ⚠️ 별점이 낮다는 이유만으로 숨기지 않는 것을 권장합니다. 좋은 후기만 골라 보여주면 실제와 다른 인상을 줘 신뢰와 법적 문제가 생길 수 있습니다.

## 코드를 고친 뒤 다시 배포할 때
**배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포** 를 해야 같은 URL로 반영됩니다.
